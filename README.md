# 🏠 Airbnb Global Market Insights & Performance Dashboard

An interactive **Power BI dashboard** analyzing Airbnb across **10 global cities** to uncover patterns in marketplace supply, pricing, customer experience, engagement, seasonality, and host trust.

## 🎯 Why I Built This

**What can Airbnb data tell us beyond the number of listings?**

That was the question behind this project.

I explored Airbnb across **10 global cities** to understand how the marketplace behaves — where listings are concentrated, how supply changes over time, how accommodation types differ in price, what customers rate highly, how review activity changes, and what trust-related patterns appear in the data.

## Why Check It Out?

This isn't just a collection of Power BI charts.

It's a **business story built from data**:

📈 **Growth** — How has Airbnb supply changed?
🌍 **Market** — Which cities drive the largest share of listings?
💰 **Pricing** — How do accommodation types compare?
⭐ **Experience** — How do cities differ in customer ratings?
👥 **Engagement** — How actively do users leave reviews?
📅 **Seasonality** — How does activity change throughout the year?
🛡️ **Trust** — What patterns appear around verification and profiles?

The goal was simple: **turn a large dataset into insights that a business or product team could actually explore and use.**

## 📊 Dataset & Analysis Scope
   Listings - Listing/host information, Location, Property and room type, Pricing and stay rules, Ratings, Host verification/trust
   Reviews - Listing ID, Review ID, Review date, Reviewer ID
